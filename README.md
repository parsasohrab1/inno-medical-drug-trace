# inno-medical-drug-trace

**پیش‌بینی مصرف و کمبود دارو**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
کمبود دارو، انقضا و موجودی نامتوازن بین داروخانه‌ها و انبارهای دانشگاه.

## محصول
پیش‌بینی مصرف دارو، هشدار کمبود و انقضا و پیشنهاد انتقال موجودی.

## کاربران و ذی‌نفعان
داروخانه بیمارستان، معاونت غذا و دارو

## قابلیت‌های هدف
- پیش‌بینی مصرف هفتگی هر قلم دارو
- هشدار انقضای نزدیک و کمبود
- پیشنهاد جابه‌جایی بین مراکز

## داده
موجودی، مصرف، تاریخ انقضا، سفارش‌ها. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
وابستگی به داده‌ی رهگیری رسمی؛ اثر تحریم و تأمین ناگهانی که پیش‌بینی‌پذیر نیست.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_drug_trace generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_drug_trace validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_drug_trace demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
`core.forecast` (رگرسیون هارمونیک هفتگی + اصلاح سطح اخیر)، هشدار انقضا/کمبود با مصرف FIFO، `suggest_transfers` (انتقال حریصانه، بدون عبور از مازاد مبدأ).
